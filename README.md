# 🏓 Ping Pong Game 🏓

A classic arcade game implemented in Python using the `turtle` module. This project provides a simple yet engaging two-player Ping Pong experience directly on your computer. The game features responsive paddle controls, realistic ball physics, score tracking, and clear visual elements, offering a fun and interactive gaming experience.

## 🚀 Key Features

- **Two-Player Mode**: Play against a friend using keyboard controls for each paddle.
- **Realistic Ball Physics**: The ball bounces off paddles and walls realistically, adding to the challenge.
- **Score Tracking**: The scoreboard keeps track of each player's score, displaying it in real-time.
- **Collision Detection**: Accurate collision detection ensures that the ball interacts correctly with paddles and walls.
- **Game Over**: The game ends when one player reaches a predetermined score, and the winner is displayed.
- **Center Line**: A dashed center line visually separates the two sides of the playing field.
- **Adjustable Ball Speed**: The ball speed is controlled to provide a balanced and challenging gameplay experience.

## 🛠️ Tech Stack

- **Language**: Python
- **Graphics**: `turtle` module
- **Core Logic**:
    - `main.py`: Main game loop and initialization
    - `paddles.py`: Paddle class for player control
    - `ball.py`: Ball class for movement and collision
    - `scoreboard.py`: Scoreboard and center line management
- **Utilities**: `time` (for controlling ball speed)

## 📦 Getting Started

Follow these instructions to get the game up and running on your local machine.

### Prerequisites

- Python 3.x installed on your system.

### Installation

1.  Clone the repository:

    ```bash
    git clone <repository_url>
    cd ping-pong-game
    ```

2.  No additional libraries need to be installed as the project uses the built-in `turtle` module.

### Running Locally

1.  Navigate to the project directory in your terminal.
2.  Run the `main.py` file:

    ```bash
    python main.py
    ```

3.  The game window will open, and you can start playing.

## 💻 Usage

- **Left Paddle**: Use the 'w' key to move up and the 's' key to move down.
- **Right Paddle**: Use the Up Arrow key to move up and the Down Arrow key to move down.
- The first player to reach the winning score wins the game.
